# 按数据类型选择方法

证据编号见 [literature.md](literature.md)。下表是结合文献与任务的设计，不是官方指定算法。

| 问题 | 处理方法与适用条件 | 核验与禁止事项 |
|---|---|---|
| ID舍入 | 保留原字符串，寻找完整ID或可核验稳定键 | 唯一性、映射基数、元数据和独立出处；不能转int恢复已丢精度或按行拼接 |
| 重复记录 | 区分重复导出与独立测量；后者保留批次/评分者 | 去重需原字段与来源证据；技术重复聚合预定规则，切分不拆同组 |
| 空卡缓存零 | 查响应输入格和公式上游，同时读取公式/缓存 | 刻度0–6、Beer#均非标签；有图形/控件需另查；summary的0不能证明已评分 |
| 少量化学缺失，原因未知 | 干净层保留NA；模型层以训练中位数为保守候选，对比均值等 | L1均值只是复现候选；中位数也可能扭曲协方差，不宣称无偏；不能全表先填再切分 |
| 非空常数与上游NA/零冲突 | 对照校准表/上游脚本标记疑似预插补或删失替代，保存原值及证据 | 先区分校准不可用和原测量缺失，不自动恢复NA；不从正值锚点推广全部逆变换。未知上游fit总体时不能宣称端到端无泄漏 |
| 有证据支持MAR/MCAR | 可比较训练折KNN或RF插补，保留简单基线 | L2；距离尺度只用训练数据，不能把目标或测试样本当邻居；NA比例不能证明机制 |
| 左删失/低于LOD | 保留censored和检测限；有单位/方法/分布依据才比较QRILC等 | L2/L3；按批次登记LOD。若实现只支持整表插补、不能训练fit后应用新样本，不得用于声称无泄漏的预测流程 |
| 全缺失列 | 从该次模型输入排除，但字典保留不可用状态 | 整表全缺失与某训练折全缺失不同；不借验证折补参数；目标不生成“真值” |
| 非数值/无穷 | 记录源坐标查编码、单位、原值 | “<0.1”保留阈值与删失语义；coerce变NA必须留账；不能静默填0 |
| 混合量纲/对数 | 逐字段transform_map；可靠键联接校准表 | 比较恒等、log10、ln及有来源偏移的残差，覆盖零/负/正和多个量级；不能全表log或exp |
| z-score感官 | 保持尺度并寻找评分者原始值/参数 | 先按评分者标准化再聚合，一组总体均值/标准差通常不能还原；不min-max到0–6 |
| 统计异常 | IQR/MAD/稳健可视化标记，查单位、记录、批次和风格 | L4/L5；真实极端保留；MAD=0另处理。截尾仅作预登记敏感性且阈值训练折拟合，不自动删5–95百分位外样本 |
| 理化边界/阈值 | 确认原始单位后检查 | log(pH)不同于pH；感官检测阈值不等于质量不合格标准；不能拿对数值与mg/L阈值比较 |
| 派生总量 | 有公式和组成单位后在原尺度重算 | sum(log c)≠log(sum c)；缺组成不能造总量，独立插补后需再查一致性 |
| 相关矩阵 | 核验别名后按轴名称对齐，查范围/缺失/对称/对角 | 仅方阵要求对称；常量相关可能未定义；44×50不补成46×50；无证据不强行对称化或缺失填0 |
| 评估准备 | 冻结组切分，Pipeline内fit | L6；内外层都重新拟合。全量相关、8.xlsx的MDI/SHAP不用于主验证特征筛选 |

三层产物：`raw`保留原字节；`clean_observed`只含确定性解析/确证修复并保留NA和状态；`model_ready/<split>/<fold>`才含训练折插补/缩放结果与参数。只要求清洗时可交第二层及第三层规则，不自动训练。

适用例：保留负DMS观测值待查尺度；7.csv全NA列隔离为不可用；2.csv描述性图保留方法冲突。这些都是有效交付，不能为了“无空值”制造信息。
